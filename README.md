# Postales de mis viajes

## Autor

Lucas Pistolesi

## Tema

Galería visual de algunos de los viajes que realicé.

## Descripción

Una web con fotografías y videos propios de distintos lugares que he recorrido. Desde la página principal se puede ingresar a cada lugar y ver una selección de momentos del viaje acompañados por descripciones breves de cada momento.


## Objetivo

Presentar mis experiencias de viaje de una manera visual, sencilla y ordenada, y permitir que el usuario recorra fácilmente los diferentes destinos.

## Contenidos

La galería incluye páginas dedicadas a Cancún, Uruguay, Ushuaia, Bariloche, San Rafael y la Costa Argentina. Cada página contiene fotografías o videos propios y una descripción breve de cada contenido.

## Decisiones de diseño

Se eligió una paleta inspirada en paisajes y viajes, con tonos verde azulado, blanco, gris claro y detalles dorados. Se utiliza la tipografía Georgia en todo el sitio. La página principal organiza los destinos con CSS Grid y las galerías utilizan Flexbox. También se incluyó una media query para adaptar la navegación, las tarjetas, las galerías y el pie de página a pantallas pequeñas.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Git y GitHub
